# KonMagic contributor instructions

- Preserve user work. This is a public repository: never commit personal
  catalogues, real source paths, filenames, document contents, credentials,
  staff identities, screenshots or local operation receipts.
- Use generic synthetic fixtures. Keep local build and QA output outside Git.
- Manual assignment controls placement. An inferred tag cannot override a
  human choice. Active child projects do not inherit archive status merely
  from an old parent folder.
- No source move/delete operation, symlink following, overwrite or hydration.
  Copy execution requires a separate reviewed preview, current full hashes,
  collision checks, capacity checks and a durable recovery receipt.
- Keep work off the main AppKit thread. Bound directory traversal and queries.
- Run the native synthetic safety checks after changes to filesystem behavior.
- Agent commits include `Co-Authored-By: Codex <noreply@openai.com>` and the
  available session link. Use a generic contributor identity in public commits.
- Do not publish local binaries as notarized unless Apple Developer ID signing
  and notarization actually succeeded.

## Public documentation screenshots

The sole screenshot exception is `docs/assets/screenshots/`: images must be generated by the synthetic documentation fixture/capture workflow, carry a hash in its manifest, and pass the documentation privacy and link checks. Never copy ordinary local QA outputs or user screenshots into this directory. Documentation examples must not contain real catalogue observations or source paths.

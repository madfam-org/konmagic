# KonMagic illustrations

These original production illustrations were generated with the built-in imagegen tool from user-supplied visual style references. The reference screenshots are private and are not distributed. Assets ship under this repository's MIT license.

- `toolkit-garden.png`: A text-free pastel panoramic garden, a cream-and-ginger wizard kitten on the left, and a sleeping cat on blank-spine books beside plants on the right; quiet central sky for native headings.
- `storage-companion.png`: A transparent cream-and-ginger kitten organizing a wooden file box beside a sprout; no text or interface elements.

Illustration generation prompts: the descriptions above plus watercolor storybook style, delicate clean outlines, powder pink/lilac/apricot/sage palette, no logos, labels or window frames. Controls, numbers, paths and evidence are always rendered by AppKit. Artwork has no runtime network dependency.

- `journey-companions.png`: Three equal transparent cells of the same kitten: Content with books/photo, Structure with pastel folders/organizer, Review with a mint checklist. Native rendering selects one cell without modifying the asset.

Generation prompt for the strip: transparent horizontal 3:1 production sprite strip; three equal square cells with one complete character each and clear separation; cream-and-ginger watercolor kitten with pink cheeks and warm clean outlines; left cuddling lavender/blue/pink books and a photo; center arranging teal/lavender/apricot folders; right beside a mint checklist; two gold sparkles per character; full bodies/props centered inside cells; no text, logos, scenery, UI, frames or dividers; readable at 76 pixels.

# Known gaps and future design work

These are limitations, not functionality that can be enabled by granting more privileges.

## Distribution and platform

Developer ID signing/notarization, a universal release strategy, updater/rollback policy, broad OS/architecture validation and systematic accessibility testing remain unfinished. The current local installer uses an ad-hoc signature.

## Content and knowledge

Native whole-machine body ingestion, richer extractor pipelines, full semantic/perceptual inference and robust external rename reconciliation are not implemented. The app consumes compatible retained readings/tags. Exact-path corrections can become stale after external changes. No Finder tag writing, unattended automation or content upload service is configured.

Rule proposals are bounded and need rerunning after draft or classification changes. Proposal preparation and approval check the complete workspace hash and correction stamp. Explorer queries clear prior aggregate groups during loading and hold old source actions until the current page completes.

## Storage compatibility

GrandPerspective gzip/XML interoperability, full translation coverage and every commercial cleanup feature are not complete. APFS shared blocks/snapshots/clones prevent an exact reclaimable-space promise. A retained scan does not supply current event history.

## Organization execution

Source moves, deletion, automatic duplicate keeper selection, perceptual duplicate removal and automatic receipt rollback/reconciliation are deliberately unavailable pending separate preservation/recovery designs. Copy output consumes extra storage. General organization does not relocate operational repositories, app databases or managed media libraries.

## Window and documentation details

Content/Storage pop-outs copy discovery context; Structure/Review local search/selection are not fully cloned. The public web docs require connectivity; the native Welcome/Tips remain local. Screenshots require refresh and inspection when controls change.

Add future work through capability contracts with safety state, evidence and test scope. Do not equate an aspirational checkbox with implementation.

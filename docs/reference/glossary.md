# Glossary

| Term | Meaning in KonMagic |
|---|---|
| Atlas | Compatible retained catalogue and whole-disk metadata inputs |
| Observation | Recorded metadata/classification/reading evidence at some time |
| Reading | Previously cached full/partial text; not necessarily a fresh body read |
| Barrier | Protection/access/content boundary that semantic tags cannot erase |
| Effective tags | Immutable catalogue classifications plus exact-path private corrections |
| Drop | An individual source file chosen for placement |
| Bucket | A coherent source folder, preserving its internal hierarchy |
| Destination node | Stable-ID virtual folder in your target design |
| Assignment | Exact source + destination node + chosen output name |
| Draft | Private planning state, not filesystem changes |
| Output root | Local directory under which approved copies would be created |
| Preview | Exact proposed paths; verified preview additionally includes current identities/hashes |
| CopyPlan | Complete bounded verified inventory tied to workspace/output identity |
| Output anchor | Existing path and device/inode pinned before approved copy |
| Stage | Private sibling temporary directory retaining in-progress output |
| Receipt | Durable plan/progress record with completed paths and retained stages |
| Logical bytes | Regular-file length |
| Allocated bytes | Metadata-reported allocation; not guaranteed reclaimable space |
| Tally | Unique counted regular files after hard-link deduplication |
| Mask | Drawing suppression that retains original area |
| Filtered view | Separately retained subset snapshot |
| Scan exclusion | Rule that can skip a subtree before traversal |
| Collection | Saved query/presentation, not a physical duplicate collection |
| Proposal rule | Explicit query + destination + naming recipe; edits draft only after review |
| Recorded disk | Historical compressed metadata ledger with aliases/exceptions |
| Page host | Independent window/controller cache using shared private decision stores |

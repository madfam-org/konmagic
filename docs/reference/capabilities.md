# Implemented capabilities and honest boundaries

The current app is a useful observation and deliberate copy organizer. “Parity” requires a capability-by-capability contract rather than a single percentage or similar screenshot.

| Domain | Current implementation | Boundary |
|---|---|---|
| Native Mac UI | AppKit controls, panels, Quick Look, Aqua/Dark Aqua | No complete accessibility certification or notarized distribution |
| Single-window journey | Cached five-page host, contextual guidance, Back/Forward | Optional independent page windows share decisions |
| Disk visualization | Persisted full trees, proportional maps, weights, package modes/colors/depth | Adaptive drawing; allocation is not exact reclaimable space |
| Storage filters | Masks, derived filtered views, compound tests and exclusions | Different coverage semantics remain explicit |
| Saved scans | Complete SQLite observation, notes, image/TSV export | Historical state, not source proof |
| Change comparison | Stable full paging and complete TSV | Metadata, not full-body diff |
| Duplicate evidence | Equal-size candidates and explicit bounded SHA-256 proof | No keeper, perceptual grouping or deletion |
| Native file/folder viewer | Current metadata, embedded Quick Look, paged list/gallery, explicit bounded thumbnails, tree/map handoff | Supported formats depend on system providers; no preview-based copy/delete authority |
| Content discovery | Compatible tags, FTS, bounded lists, trees/maps/relations | No native full-machine body-ingestion service yet |
| Human classification | Exact-path private corrections, Undo | No Finder tag writes or descendant cascade |
| Collections/rules | Saved bounded queries and reviewed exact proposals | No unattended apply/watch automation |
| Structure | Virtual nodes, drops/buckets, naming, draft Undo | Managed operational collections remain held |
| Verification | Fresh identities, complete hashes, capacity/collisions | 5,000 entries / 100 GiB per bounded plan |
| Copy | Metadata-preserving stages, exclusive publish, receipts | Originals retained; no global batch rollback |
| Volume context | Bounded read-only APFS/volume/snapshot info | No purge/mount/delete |
| Documentation | Searchable public site, contextual native links, invented screenshots | Online manual; local Welcome/Tips remain available |

The [GrandPerspective contract](../GrandPerspective-capabilities.md) details implemented, partial and missing compatibility. The [macOS alternatives research](../macOS-alternatives.md) maps 95 tools and 44 capability contracts with primary-source links. Its dated matrix is not proof of parity against every new release.

# Troubleshooting without losing context

| Symptom | Likely explanation | Safe next step |
|---|---|---|
| Catalogue unavailable | Missing/moved/incompatible database or denied access | File → Connect catalogue; select the containing folder and preserve the originals |
| Empty Downloads view | Catalogue scope differs or retained records are absent | Select All retained content; inspect Recorded disk separately |
| A scan is partial | Access, cancellation, depth or storage guard | Inspect recorded issues; narrow the root or obtain appropriate macOS access |
| A record exists but the source is gone | Historical observation | Refresh current metadata; do not treat it as verified source content |
| A retained excerpt is unavailable | No reading, shared-hash mismatch or protected barrier | Inspect evidence; do not bypass protection or claim it was read |
| Copy disabled | Empty/unverified/stale draft or active operation | Inspect Review, verify again when idle, and review any holds |
| Destination collision | Existing path or case/Unicode equivalent | Choose a different destination/output name; no overwrite is offered |
| Preview exceeds limits | More than 100 assignments, 5,000 entries or 100 GiB | Split a coherent batch; narrow rules and review the complete new plan |
| Capacity hold | Copy would leave at most 10 GiB free | Choose a sufficiently large local/external output root; retain originals |
| Operational collection refused | Repository, managed library, app or sensitive data | Keep that collection in place and use its own supported migration workflow |
| Another instance is running | Private state lock already held | Raise the existing app; do not delete its live lock |
| Web help cannot load | Browser/network/Pages availability | Use native Tips/Welcome; browse Markdown in the repository when available |
| Receipt reports failed/publishing | Interrupted staged/published copy | Preserve all exact paths and reconcile the receipt before a new plan |

## Access is not authority

macOS privacy permission and KonMagic’s safety eligibility are separate. Full Disk Access may permit observation of a folder but does not make an application database, source repository or credential safe to reorganize. The app’s copy policy remains restricted to ordinary sources under standard user-content roots.

Cloud metadata is not downloaded content. iCloud synchronization is not a complete machine backup. Keep an independently reviewable preservation strategy before any future deletion; current KonMagic does not delete sources.

## A useful bug report

Provide version/build, macOS version, compiler/architecture if relevant, the page/action, whether the dataset was recorded or live, and a reproduction using invented files. Do not attach your catalogue, full receipts, private file paths, document contents or normal local screenshots to a public issue. See [contributing](../developer/contributing.md).

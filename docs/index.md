## What the app does today

KonMagic observes and proposes. Native scans read metadata; compatible Atlas catalogues supply previously retained tags and excerpts. Personal corrections live in a private overlay. Assignments edit a draft. Verification reads complete eligible source data to produce a bounded copy plan; copying requires another explicit confirmation. Originals remain intact.

Moving, deletion, cloud hydration, unattended cleanup and automatic duplicate removal are unavailable. This distinction is central to the interface and its engineering. See the [capability matrix](reference/capabilities.md) and [known gaps](reference/roadmap.md) for precise scope.

The desktop app links to this site through **Help → KonMagic Documentation**, **Help → Help for This Page**, **Help → Developer Handbook**, and the Toolkit’s Documentation button. Opening documentation sends only a static public URL to your browser.
